# 浪浪山：妖怪合伙人 · 本地网页版

宝可梦式收服对战卡牌游戏，基于 70 张浪浪山卡牌原画。纯本地运行，无需联网。

## v2.6 更新 · 在线对战

- **房间制 P2P 对战**（主城新增「⚔️ 对战」页）：创建房间生成 **4 位纯数字房码**（如 8826），好友输入即可进入；底层用 WebRTC（PeerJS）直连，仅在进入对战页时联网加载一次连接模块，其余玩法完全离线。
- **1v1 单挑 / 2v2 组队**：房主可随时切换模式。2v2 下同方队友各带卡组，**队友卡组属性互通可见**（等级/攻防速明细）；场上妖怪归属谁，就由谁指挥。
- **换边与双重准备**：点自己/队友的「换边」即可调换阵营（房主也可移任何玩家）；所有人类玩家都点「准备」后房主才能开战。
- **3 缺 1 AI 补位**：空位可一键「AI 补位」，AI 队友自带随机卡组、自动出招；对战中队友掉线也会自动由 AI 接管。
- **主机权威同步**：双方指令合议后按速度结算，快照实时推送；胜方 +150 / 败方 +40 山核桃。

## v2.5 更新 · 抽卡聚宝阁

- **新人三连抽**：新玩家上线不再三选一，而是直接随机抽 3 张卡片组成初始队伍，首抽必出 SR+。
- **聚宝阁抽卡**：主城新增「🎴 抽卡」页，山核桃累积到 300 可单抽一次；抽到的妖怪按当前队伍平均等级（6~20）加入名册。
- **概率与保底**：UR 2% / SSR 10% / SR 30% / R 58%（万次抽样实测一致）；连续 9 抽未出 SSR，第 10 抽必定 SSR 以上，页面实时显示保底进度。
- **揭示动画**：卡面翻出 + 按稀有度发光（UR 橙 / SSR 金 / SR 紫 / R 蓝），显示稀有度、定位、阵营、身份。

## v2.4 更新 · 神魔妖鬼 · 阵营组合

- **双维度体系**：每张卡有「阵营」和「身份」两个标签。
  - **身份（神/魔/妖/鬼）** 承担克制：神→魔→妖→鬼→神，克制方伤害 **+30%**；同身份技能 +20%（同源）。克制盘小圆盘与放大图均已换成身份环。
  - **阵营（莽苍岭/百毒涧/碧波潭/幽冥洞）** 不参与克制，只做收录分组，**后续可继续扩展**；每个阵营有独立技能组与外观。
- **阵营搭配组合**：每次战斗按双方出场阵容自动结算——三同源（伤害+10%）、山海同盟（生命+10%）、裂谷猎团（攻+8%）、昼夜巡山（速+10%）、幽波引渡（防+10%）、毒沼滋生（每回合妖力+4）、幽瘴毒巢（跳伤+2%上限）、浪浪山混编（妖力获取+15%），HUD 顶部展示双方组合徽章。
- **同稀有度总属性拉平**：UR 9800 / SSR 8650 / SR 7600 / R 6350 为基准（按角色定位微调，30 级总属性差 ≤±1%），角色差异体现在攻防速分布而非总量。

## v2.1 更新 · 边玩边学

- **边玩边学教学战**：新玩家自动进入「入门试炼」——不用读文字说明书，跟着金色聚光高亮一步步实战学会出手、克制、收服；随时可跳过，也能在标题页/主城「玩法指南」重开。原「玩法说明」改为指南入口：边玩边学 / 克制关系速查 / 文字速查 三选一。

## 怎么玩

**方式一（最简单）**：双击 `index.html`，用浏览器打开即可。

**方式二（推荐，支持手机局域网访问）**：

```bash
cd langlangshan-game
python3 -m http.server 8802
# 浏览器打开 http://127.0.0.1:8802
# 手机连同一 Wi-Fi 访问 http://<你电脑的IP>:8802
```

## 玩法要点（宝可梦规则）

- 每场 1v1 出场，可随时换人（消耗回合）；速度快的先出手
- 每只妖怪 4 个技能，各有 PP 次数，战斗后自动回满
- 属性克制链：**内卷流 → 摸鱼流 → 整顿流 → 内卷流**（互克 ×2，反向 ×0.5）；摆烂流中性
- 同属性技能有 1.5 倍加成；有会心一击（1/16）
- 野生妖怪可用「紫金红葫芦」收服：对方血越少、稀有度越低越容易成功
- 头目战不可收服/逃跑，但通关直接掉落卡牌
- 战斗获胜得经验，升级能力成长；山核桃可在商店买道具
- 进度自动存到本机浏览器，下次打开点「继续冒险」

## 分享给同学试玩

**方式一 · 同一 Wi-Fi 局域网（现场演示最快）**

```bash
cd langlangshan-game
python3 -m http.server 8802 --bind 0.0.0.0
```

同学手机连同一 Wi-Fi，浏览器打开 `http://<你的局域网IP>:8802`（本项目内已生成 `同学扫码试玩.png`，扫码即可）。
注意：① macOS 首次运行如弹出防火墙提示，选"允许"；② 部分校园/公司 Wi-Fi 开了设备隔离，同学连不上时改用手机开热点、电脑连热点再访问。

**方式二 · 发单文件（不用建服务器）**

把 `浪浪山单文件版.html`（约 7MB，全部图片已内嵌）通过微信/AirDrop 发给同学：
- 安卓：微信里下载后选「用浏览器打开」，或文件管理器里用 Chrome 打开
- 电脑：双击即玩
- iPhone：本地 HTML 无法直接用 Safari 打开，建议用方式一或方式三

**方式三 · 公网链接（不同城市也能玩，电脑需开机）**

```bash
brew install cloudflared
cloudflared tunnel --url http://127.0.0.1:8802
```

会输出一个 `https://xxxx.trycloudflare.com` 临时网址，发给任何人即可；电脑关了链接就失效。

**方式四 · 正式部署（长期可用）**

整个文件夹是纯静态站，可零改造发布到 GitHub Pages / Vercel / Netlify / 阿里云 OSS，获得永久网址。
